# 리틀 아라드 : 크리처 타워 — 플레이 프로토타입

던전앤파이터 미니 모드 기획서 『리틀 아라드 : 크리처 타워 Ver 0.7』을
실제로 플레이 가능한 형태로 구현한 프로토타입입니다.

**▶ 플레이 : https://<사용자명>.github.io/<저장소명>/**

## 무엇인가

기획서의 코어 루프를 문서가 아니라 동작하는 빌드로 검증한 결과물입니다.
빌드 도구 없이 HTML 파일 하나로 되어 있고, 이미지 · 음원까지 전부 파일 안에 들어 있습니다.

- 진입 → 편성 → 20층 등반 → 포획 → 강화 드래프트 → 구간 정산 → 승급 · 역할군 패시브
- 5 · 10 · 15층 엘리트, 20층 보스
- 크리처 12종, 진화 2단계, 등급 7단계(커먼 ~ 태초)
- 상태이상 12종, 버프 · 회복 · 부활
- 이벤트 미션(일일 · 주간 · 업적), 도감
- 진행 상황은 브라우저에 저장됩니다

## 조작

| 키 | 동작 |
|---|---|
| 방향키 | 커서 이동 |
| X | 선택 |
| C | 취소 · 뒤로가기 |
| ESC | 도전 중 퇴장 경고 |

마우스로도 모두 조작할 수 있습니다.
첫 진입 시 튜토리얼이 뜨며, 메인의 **가이드** 에서 다시 볼 수 있습니다.

## 밸런스 검증

기획서 4-1의 성장 단계별 클리어율 목표를 스크립트 시뮬레이션으로 맞췄습니다.

| 조합 | 기획서 목표 | 실측 |
|---|---|---|
| 초회차 · 커먼 | 10~15층 도달 | 13.6층 |
| 승급 초반 · 레어 | 40~60% | 45% |
| 승급 중반 · 레전더리 | 60~75% | 59% |
| 승급 완료 · 태초 | 75~90% | 88% |

밸런스 상수는 파일 상단 `BAL` 객체 한 곳에 모여 있고,
층수는 `BAL.finalFloor` 값 하나로 바꿀 수 있습니다.
